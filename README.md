# Anirudhra Singh - Personal Portfolio

This is my personal portfolio website made as a frontend assignment. I used HTML, CSS and JavaScript to build the different sections and add simple interactions.

## Features
- Navigation links to the page sections
- Introduction and hero section
- Project cards
- Recommendations carousel
- Contact form with front-end validation
- Responsive layout for smaller screens

## Technologies Used
- HTML
- CSS
- JavaScript

## Run Locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or open it directly in a browser.

## Personal Details
Update the email address, GitHub link, LinkedIn link and other contact placeholders in `index.html` before publishing. Project descriptions are starter text and can be changed to match your actual work.

## Note
The contact form is a front-end demo. It does not send or store submitted information. The recommendation cards contain sample text and should be replaced with genuine feedback before being presented as real testimonials.
